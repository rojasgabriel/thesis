# Paper story

As of 2026-11-16; [numbers and figures](glm.md), [controls](glm_checks.md).

**Question:** how do V1 flash responses change around center-port exit?

**Finding:** the observed increase differs across sessions. The corrected model
comparison does not establish a shared positive flash × exit contribution;
positive effects remain compatible with the pooled interval. In-port movement
is associated with smaller responses in the original two mice. These are task
periods and observational associations, not isolated causal movement effects.

**Scope:** GRB006 and GRB064, plus provisional GRB061 for the main flash analyses.
Most controls still cover only the original two mice; the gap/rank gain control
varies by group. GRB061 fails the required-wait criterion and has low sensitivity.

**Figure order:** task → observed responses → encoding model → matched and
leak-corrected comparison → gain/adaptation/movement controls → decoding.

**Next:** more qualifying sessions per mouse; extend controls to GRB061; test
new terms on new data; use eye/head measurements to separate visual-field and
state changes.
